# Contributing

Thank you for helping improve the Onchain Finance community specifications.

## Open an issue

Use GitHub Issues for public specification feedback. A useful report identifies:

- The affected specification and section.
- Whether the concern is an error, ambiguity, interoperability issue,
  security or privacy concern, or stale reference.
- The current wording or behavior.
- The proposed correction and supporting primary sources, when applicable.

Use the specification-feedback issue form when it fits. Ordinary issues remain
available for concerns that do not fit the form.

Do not include confidential business information, personal data, credentials,
private keys, or regulated customer information in an issue.
